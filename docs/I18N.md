# I18N 开发说明

## 当前实现

- 语言状态：`/Users/i/Code/huanvae/frontend/src/store/settingsStore.ts`
- 词典：`/Users/i/Code/huanvae/frontend/src/i18n/messages.ts`
- Provider / Hook：`/Users/i/Code/huanvae/frontend/src/i18n/I18nProvider.tsx`
- 全局挂载：`/Users/i/Code/huanvae/frontend/app/providers.tsx`

支持语言：
- `zh-CN`
- `zh-TW`（当前继承 `zh-CN`）
- `en-US`
- `ja-JP`（当前继承 `en-US`）

## 使用方式

```tsx
import { useI18n } from '@/i18n/I18nProvider'

function Example() {
  const { t } = useI18n()
  return <h1>{t('settings.title')}</h1>
}
```

带参数：

```tsx
t('home.welcomeBack', { name: 'Alice' })
```

## 新增翻译

1. 在 `src/i18n/messages.ts` 增加 key。
2. 在页面组件中用 `t('...')` 替代硬编码文案。
3. 运行 `pnpm exec tsc --noEmit` 检查。

## 后续建议
